# Sales Forecasting Dashboard

## Overview
This project is a Sales Forecasting Dashboard built using Python, PostgreSQL, Streamlit, Pandas, NumPy, and Plotly.

The system analyzes historical sales data, visualizes trends, and predicts future sales performance using linear forecasting techniques.

---

## Features
- Interactive Streamlit Dashboard
- Sales Trend Visualization
- Future Sales Prediction
- Monthly Sales Analysis
- PostgreSQL Database Integration
- Download Filtered Data as CSV
- Dynamic Date Filtering

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- PostgreSQL
- SQLAlchemy
- Streamlit
